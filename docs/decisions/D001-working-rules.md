## Decision (one line)

Use the working rules in [CLAUDE.md](../../CLAUDE.md): Compass, activity log, decision and
approach files, manual git.

## Why

So status, decisions and failed tries are on record and the project can be restarted after days away.

## Options considered

| Option | For | Against |
|---|---|---|
| File-per-record docs + Compass (chosen) | One click to open any decision; history kept | Some overhead per change |
| Notes only in README | Light | History gets lost; hard to restart |

## Evidence

User request, 2026-11-25.
